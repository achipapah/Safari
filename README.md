# Rhonda Spirit Tours Website

A responsive, static website for Rhonda Spirit Tours, ready for GitHub Pages.

## Publish with GitHub Pages
1. Create a new GitHub repository, for example `rhonda-spirit-tours`.
2. Upload `index.html`, `style.css`, `script.js`, and the `assets` folder to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch **main** and folder **/ (root)**, then Save.
6. Wait for GitHub Pages to publish the site. Your address will look like:
   `https://YOUR-USERNAME.github.io/rhonda-spirit-tours/`

## Update before/after launch
- Replace `assets/logo.jpg` if you receive a higher-resolution transparent logo.
- Review the tour prices and package details before publishing. Prices are shown as supplied.
- The Zanzibar package is shown as “Request a quote”.
- The site uses externally hosted Unsplash photography and Google Fonts, so visitors need an internet connection for those assets.
